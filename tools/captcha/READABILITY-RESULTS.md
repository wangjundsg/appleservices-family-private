# 可读性模型 v1：首轮真实实验结果

2026-11-27。**已完成训练，但未达到实验验收目标，不建议用于生产拦截。**
低误放率伴随着极低可读保留率；不能仅凭 refresh 召回率宣布模型可用。

## 模型与固定配方

- 版本：`readability-mnv3s-v1-6fc088e046a2`。
- 官方 MobileNetV3-Small ImageNet-1K V1，分类头 576→1；927,585 参数。
- 5 epoch 冻结骨干 + 10 epoch 末端微调；固定种子 20261127，batch=32，CPU 2 线程。
- 无合成负例、无数据增强。类别权重：refresh=3.40667，readable=0.58601。
- 纯训练阶段耗时 51.95 秒，不含安装、下载、数据处理、校准与基准测量。
- 原始预训练 SHA-256：`047dcff4addef86ea5bc2eff13c9614dc11f47ab1160d0a71a25e7db994f4e1f`。
- 最终模型 SHA-256：`207c18624c1caab2e01d4dc5fa994db8536722ef1618ef93c24df6779c94a6b8`。
- 模型文件大小 **3,830,635 字节，约 3.65 MiB**，不含 Python/PyTorch 运行环境。

完整训练命令、来源和数据审计见 [READABILITY.md](READABILITY.md)。依赖已锁定到

## 数据与阈值

人工确认“刷新不必死磕”代表太模糊分不清后，冻结 **831 readable / 150 refresh**。
原始 OCR 表保持原样；本任务使用独立人工判定记录。各来源批次保持完整，SHA-256 无交叉，
近重复启发式检查未发现需合并的跨批次图片。

| 集合 | readable | refresh | 用途 |
| --- | ---: | ---: | --- |
| 训练 | 436 | 75 | 模型参数 |
| 校准 | 116 | 15 | 单调 Platt 校准及阈值 |
| 独立验证 | 279 | 60 | 最终真实效果 |

Platt 参数 slope=0.4958267122、intercept=1.4527344828。
**仅当 readable_probability > 0.9448492885 时放行**，其余刷新。
阈值仅来自校准集，独立验证前已保存模型与阈值。
校准集矩阵为 `[[15, 0], [102, 14]]`：0/15 不可读误放，但仅保留 14/116 可读图。
校准集 Brier 从 0.13529 降至 0.09562；这是用于拟合的同一集合上的诊断值，不能视为独立校准效果。

## 独立真实验证

矩阵行为真实标签，列为模型决策：

| 真实标签 | 预测 refresh | 预测 readable |
| --- | ---: | ---: |
| refresh | 59 | 1 |
| readable | 250 | 29 |

| 指标 | 结果 |
| --- | ---: |
| refresh 召回率 | 59/60 = **98.33%** |
| false-readable rate（不可读误放率） | 1/60 = **1.67%** |
| readable 保留率 | 29/279 = **10.39%** |
| 总体放行覆盖率 | 30/339 = **8.85%** |
| 总体准确率 | 88/339 = **25.96%** |
| 放行结果中实际 refresh 占比 | 1/30 = **3.33%** |
| 独立验证 Brier score | **0.13233** |

误放率的双侧 95% 精确二项区间约 **0.042%–8.940%**，单侧 95% 上界 **7.664%**。
样本来自单日同一样式，且批次内相关性使逐图二项区间可能偏乐观，不能宣称真实误放率已被保证在 5% 以下。
预设验收条件是误放率点估计≤5%、可读保留率≥50%；**后者明显失败**。
没有使用独立验证结果重新选阈值或继续挑选模型。

## CPU 单张基准

AMD Ryzen 7 4800H，Windows 11；单线程、batch=1，预热 20 次后测量 1,000 次。
端到端测量轮换验证图片，包含文件读取、解码、预处理和推理；文件可能命中系统缓存。
模型加载和首次初始化不包含在热调用耗时内；机器有其他工作负载，非隔离硬件基准。
