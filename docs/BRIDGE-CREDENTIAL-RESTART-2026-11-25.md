# 设备桥接凭据跨 worker 重启

首次激活知道密码时，以当前 Windows 用户的 DPAPI 加密保存桥接凭据。worker 仅用已有设备会话重启、未再传入密码时，读取同一账号的本机凭据，补齐 8788 首次导入所需信息。凭据文件不进入版本库，不写明文或可移植解密密钥，不出现在普通状态响应。

对应测试覆盖密文无明文密码、重新创建 worker 控制实例后恢复、身份不匹配拒绝、密码更新。非 Windows 保持内存行为，不提供明文降级。

部署新的 worker 文件不会改变正在运行的设备连接。后续用新 worker 登录或启动才启用该行为；此前从未保存过本机凭据的工作区，需要一次正常的带密码登录建立文件。已被 8788 导入的账号沿用其已有加密凭据，不必为此重登。

DPAPI 受 Windows 用户和机器绑定，迁移台式机时需重新提供凭据，不能假定复制文件即可解密。工作区还包含其他尚未提交的 dashboard 改动，本次提交只包含 control 桥接及凭据文件忽略规则。
