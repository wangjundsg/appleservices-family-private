# 国区激活与家庭共享

母号：设备激活 → 在场完成媒体商店首次使用、付款绑定与 50GB 购买 → 核验付费容量 → 关闭自动续费并回读 → 创建家庭 → 开启储存共享。

子号：设备激活 → 核对指定母号和名额 → 加入家庭 → 启用共享空间 → 双端核验。子号不绑定支付、不购买订阅、不兑换礼品卡。

一个家庭最多是组织者加五位成员；50GB 是全家共用的总容量，不是每人 50GB。各账号的私人资料仍独立。依据：[Apple 家庭共享 iCloud+](https://support.apple.com/zh-cn/108783)。关闭自动续费保留本计费周期内的服务；到期后需要重新开通，不自动再次购买。

## 面板入口

构建 `cmd/dashboard`、`cmd/trusted-device`、`tools/familyinspect`、`tools/accountsetupcheck`、`tools/nacexchange`；可使用 `tools/apple-pipeline/panel.ps1 -Build`。运行中的旧面板不会因构建自动换版本，需要正常重启面板；账号后台按需重新连接。

已有账号在概览的“国区激活与家庭共享”卡片操作：

1. 选择当前账号的母号/子号用途；子号选择明确的母号。
2. 密码只用于本次后台连接，提交后清空输入框，不能写入文档、日志或版本库。已带密码在线的账号可以留空。
3. 勾选流程授权，点击“开始 / 继续”。按当前授权处理 Apple 返回的国区条款；子号需要验证码时在同一个账号完成验证，后台检测激活和在线后继续。不要循环重启登录或发送短信。
4. 母号没有付费容量时停在付款阶段。用户在场完成扫码及购买后，再点继续。自动化入口不提供扣款/绑定支付操作；购买按钮仍需独立确认实时 CN 50GB CNY 6/月报价。
5. 母号完成准备后再运行子号。母号后台需保持在线并有进程内密码，用于刷新家庭 GSA；密码缺失时带密码重新连接母号，不能把持久化 PET 当密码。

子号点击“开始 / 继续”通过 `/api/cn-family-background` 保存账户绑定的后台任务。后台按“核对并入组 → 加入共享空间 → 双端核验”推进；关闭网页继续运行，重启面板后读取已保存步骤。若写入执行中断，先只读核验，不能自动重放未知结果。满员、资格不符、密码缺失或读回不明时暂停，核对后点击继续。

勾选“以后新添加的账号激活后，自动加入此母号”会保存默认组织者以及当时已有账号的排除列表；仅之后新添加的非注册管线账号自动排队，激活且在线后接续。不会改动现有其他账号，也不会自动选择另一个母号或退出其他家庭。可以停止当前子号任务，也可单独关闭新账号默认规则。母号容量、成员关系和名额在每次写入前实时核对；旧母号缺少 `family-ready.json` 不应导致本地误拒绝。

任务与规则只保存账号目录 ID、步骤和状态，不保存密码。恢复已有会话时若内存密码缺失，带密码重新连接相关账号即可。子号任务不包含任何购买或支付操作。母号准备流程仍由页面顺序推进，需要保持页面打开，付款保持用户在场。新注册任务复用同一套激活/家庭适配器，国区母号停在“等待付款”；付款后在注册任务卡片点击“已付款，继续关闭续费与共享”。该续跑不重新注册、不重新申请短信号码。

## 付款阶段的已验证路径

先读 [购买 skill](../icloud-plus-purchase/SKILL.md)。从未使用 App Store/iTunes 的账号可能需要在官方 Apple Music 网页完成首次媒体商店登录、2FA 和欢迎页；不要订阅 Music 或试用。一次实测中，完成这一步后 matched-bag Store 认证和抖音付款保存均成功，不能将所有 `5005` 都归因于此。

官方 Apple 账户页的抖音扫码：生成新二维码 → 用户手机授权 → Apple 保存付款方式 → 重新读取付款列表。扫码成功不能代替 Apple 保存成功。沿用已有真实账单资料；缺失时使用用户提供的资料。支付宝/微信是否可用以当前官方入口返回为准。

国区购买使用匹配 bag 的 `storage-skill-auth-local` → `storage-skill-purchase-cn`，或购买 skill 的 `icloudpurchase -claude-skill -native-store -confirm-cn-50gb`。付款等待卡片不自动执行这两步。用户已在其他入口开通的，读取容量后跳过购买。

## 状态与重入规则

- 激活以同账号有效 MME 和实时配额为准；GSA 登录、接受条款、设备列表单独成功都不够。实现沿用 [激活 skill](../icloud-mac-nac-activation/SKILL.md)。
- 母号续费核验从新建的同账号 Store 会话读取订阅，要求明确的布尔 `isAutoRenewEnabled=false`；缺字段/读取失败保持未确认。取消前绑定 CN 50GB 订阅，取消后核验订阅仍在和付费容量。
- 创建、共享、加成员前刷新组织者的家庭 GSA，私有 `family-gsa.json` 与原账号绑定且仅短期采用；不覆盖正在运行的账号主会话。
- 加成员先读组织者与子号状态。已加入时用 `familyinspect -verify-pool-member-dir` 核对确切账号，不以相同人数或容量猜测同一家庭。名额按成员、待处理成员和邀请保守计数，达到六人停止。
- 只重试读取。购买、加成员或取消响应不明时先核验，不盲目重放；加成员 HTTP 成功和超时两种路径都回读组织者最新成员快照。
- 子号已是其他家庭成员时停止，不自动退组。购买共享、位置共享保持关闭。
- 完成要求：两端成员关系匹配，子号 `storage_known/participating/available/enabled=true` 且共享容量至少 50GB。HTTP 200、邀请存在或“共享可用”单独不够。

成员写入细节参见 [家庭共享 skill](../icloud-family-sharing/SKILL.md) 和其协议参考。所有账号状态、原始响应、令牌、二维码、密码及验证码留在受保护的 Git 忽略目录，不写入本 skill。

## 验证边界

已有实测完成过一组母子账号的 CN 50GB 购买、关闭续费和家庭共享。组合自动化用离线测试验证顺序、付款等待、满员拒绝、确切家庭绑定、缺失续费状态拒绝和子号不购买；不得把这些测试说成新账号已经再次付费验收。美国礼品卡全自动化另行验证。
